Farside ETF flow is daily supplemental context acquired through certified browser-backed scheduled retrieval; direct Node HTTP remains edge-rejected. The crypto corpus is frozen and bounded, and D2 source publication remains PENDING.

If the live Binance overlay disconnects, continue unchanged with the governed reference value and as-of timestamp. The demo does not depend on the live overlay.
