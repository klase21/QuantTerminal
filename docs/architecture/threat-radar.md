# Threat Radar

## Purpose

Threat Radar identifies what could invalidate the current market direction.

## Threat Types

- liquidation cluster
- funding crowding
- OI divergence
- macro event
- ETF flow reversal
- narrative exhaustion
- prediction market reversal

## Output

Each threat should include:

- severity
- source
- trigger level
- expected impact
- historical examples

## Usage

- Dashboard risk panel
- Trade invalidation
- Scanner filtering
