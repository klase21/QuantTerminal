# Temporal Compression

## Purpose

Temporal Compression summarizes many market events into a readable timeline.

## Problem

Replay and event timelines can become unreadable when too many events overlap.

## Rule

Use short terminal-style labels.

Examples:

- LIQUIDATION CLUSTER ¡æ LIQ CLUSTER
- LARGE LIQUIDATION ¡æ LARGE LIQ
- FUNDING SHIFT ¡æ FUNDING
- OI SPIKE ¡æ OI+
- OI DROP ¡æ OI-
- PRICE BREAKOUT ¡æ BREAKOUT
- PRICE REJECTION ¡æ REJECT

## Future

Use adaptive labels:

- desktop: short label
- dense timeline: symbol label
- hover/detail panel: full explanation
