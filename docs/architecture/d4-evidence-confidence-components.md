# D4 Evidence Confidence Components

Confidence remains component-based:

- availability;
- coverage;
- freshness;
- quality;
- consistency;
- provider diversity;
- conflict burden;
- policy completeness;
- model certainty where applicable.

Each component has independent state, evaluation references, policy version, optional governed value/unit, and limitations. Missing remains missing. Provider Tier and prediction probability are separate.

Phase 1 defines no numeric weights, thresholds, aggregate, or cross-Profile comparability. A later aggregate requires approved calculation and reconstruction policy. Consumers must retain component drill-down.
