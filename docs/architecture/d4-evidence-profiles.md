# D4 Evidence Profiles

Profiles are governed assembly recipes, not consumers and not executable code.

The proposed registry contains Market State, Market Move Context, Replay Event Context, Sector Context, and Macro/ETF Context. Every entry is PROPOSED and explicitly limited. No Profile supplies numeric thresholds, publication approval, or runtime behavior.

A Profile declares required datasets and roles, referenced Consistency Rules, assembly/publication policy versions, schema version, and consumer-neutral ownership.

Dashboard, Replay, Research, Markets, Scanner, and Trade consume Packet projections. Scanner priority and Trade planning remain downstream interpretation; they are not Core Profile facts.

Profile activation requires a later approved policy, exact D2 dataset eligibility, temporal/resolution policy, and isolated certification.
