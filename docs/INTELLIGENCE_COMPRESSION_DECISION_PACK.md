# Intelligence Compression + Decision System Pack

## Added
- Sector Depth Layer: shows internal leaders behind each sector/narrative without cluttering the main universe.
- Scenario Branches: converts the current read into next possible paths with trigger/consequence.
- Temporal Compression: compresses current flow into one market story line.
- Minimal/Advanced compatibility: detailed scenario + depth tools remain secondary while core view stays readable.

## UX Goal
Keep the main dashboard instantly readable while giving advanced users a fast way to inspect why a narrative is strong and what could happen next.
