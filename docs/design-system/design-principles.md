# Design Principles

**Owner:** Product Design  
**Status:** Canonical

## Visual First

Use visual hierarchy to reveal the state before relying on explanation. Charts,
timelines, status marks, and evidence structure should reduce reading effort,
not decorate it.

## Evidence First

Observed evidence, source, freshness, and availability appear before reasoning
or action. Visual prominence must never reverse this dependency.

## Explain, Don't Predict

Interfaces explain observed conditions and relationships. Predictive language,
certainty, and recommendations require their own approved contracts and may
never be implied by color or confidence styling.

## Progressive Disclosure

Begin with the clearest useful state, then reveal evidence, charts, replay,
research, and repository detail. Depth remains available without becoming the
default burden.

## 5-Second Rule

Every primary screen communicates its purpose, current state, and next useful
path within five seconds. Competing headlines indicate a hierarchy defect.

## Professional Workflow

Support rapid scanning, comparison, keyboard use, persistent context, and dense
analysis where the user chooses it. Professional density must remain ordered.

## Human Decision Authority

The interface supports judgment; it does not impersonate it. Users can inspect,
challenge, defer, or reject reasoning and remain in control of consequential
actions.

## Trust Before Attention

Prefer honest limits, calm urgency, and visible provenance over engagement
mechanics. Missing evidence stays missing. Experimental evidence stays marked.

## Consistency Over Novelty

The same state, action, and information object should look and behave the same
across screens. Novel presentation is justified only when it improves meaning.

## Composable Components

Components represent stable product concepts and combine without acquiring
hidden responsibilities. Composition preserves source lineage, states, and
accessibility.

## Principle Resolution

When principles appear to compete, resolve them in this order:

1. Truth and source transparency.
2. Human safety and accessibility.
3. Primary user understanding.
4. Responsiveness and graceful degradation.
5. Consistency and reuse.
6. Density, personalization, and visual refinement.
