# Elevation and Motion

**Owner:** Product Design  
**Status:** Canonical

## Elevation Levels

| Level | Meaning |
| --- | --- |
| Base | Primary page or workspace plane |
| Raised | Menu, selected tool, or temporary local emphasis |
| Overlay | Popover, drawer, or context surface above work |
| Modal | Blocking decision that requires explicit resolution |
| Critical | Rare safety, destructive action, or session-level interruption |

Elevation communicates interaction order, not importance of evidence. Borders,
surface contrast, and spatial placement should do most grouping work; shadows
remain restrained.

## Motion Principles

Motion explains change, preserves orientation, and confirms action. It must not
manufacture urgency, decorate idle screens, or obscure data updates.

## Canonical Motion Uses

- Transitions: connect known states without delaying work.
- Loading: show bounded progress or honest indeterminate activity.
- Expansion: preserve the relationship between summary and detail.
- Hover: reveal affordance without moving surrounding layout.
- Focus: make keyboard location unmistakable.
- Refresh: distinguish updated content from continuously animated content.

## Animation Rules

- Prefer short, interruptible transitions.
- Do not animate raw market changes in a way that prevents reading.
- Do not use perpetual decorative animation.
- Preserve chart scale and context during updates where possible.
- Layout changes should not cause unexplained jumps.
- Motion never replaces a state label or completion message.

## Reduced Motion

Reduced-motion preferences remove non-essential movement, use immediate state
changes where safe, and retain focus, progress, and update meaning through
static visual and textual cues.
