# Pattern Taxonomy

**Status:** Canonical pattern taxonomy  
**Owner:** Product / Design

## Purpose

This taxonomy organizes product patterns by product function so future
Dashboard, Replay, Research, Markets, Scanner, Trade, Evidence Card, and Design
System work can find the relevant pattern set quickly.
