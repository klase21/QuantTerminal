## 3. Information Architecture

Navigation is entity/search driven. Hierarchy begins with entities, wallets, transactions, and flows. Grouping is investigation-oriented: profile, holdings, transfers, counterparties, alerts, and graph views. Progressive disclosure works through drilldowns from entity to transaction. Density is high but purposeful. Search is central. Filtering supports chain/entity/transaction focus. Workspace is investigation-session oriented.

## 4. Visualization

Charts show balances and flows. Cards summarize entities and wallets. Heatmaps are secondary. Timelines and transaction histories matter. Tables are important for transfers and holdings. Network graphs are a key pattern. Animations are useful only when clarifying flows. Typography and spacing support dense crypto data. Color language distinguishes entities, flows, risk, and direction.

## 5. Decision Support

Users reach conclusions by tracing entities, flows, and transaction context. Evidence is transaction-backed, but label confidence matters. Reasoning is investigative rather than predictive. Historical context exists through transaction history. Confidence must be explicit when labels or attribution are uncertain. Counter-evidence should include alternative entity interpretations or incomplete labels.

## 6. UX

Learning curve is medium-high. Onboarding requires understanding addresses, labels, and flows. Interaction model is search, drilldown, graph exploration, alerts, and filtering. Customization is moderate. Productivity is high for investigators. Desktop is primary. Mobile is useful for monitoring. Accessibility depends on graph readability.

## 7. Strengths

- Entity-centric intelligence.
- Strong investigative workflow.
- Network and flow visualization.
- Converts raw chain data into human objects.
- Search-to-investigation loop.

## 8. Weaknesses

- Label confidence can be misunderstood.
- Less useful for users without on-chain literacy.
- Graphs can become visually complex.
- Entity framing may imply certainty when attribution is partial.
