## 1. Product Identity

| Field | Analysis |
| --- | --- |
| Mission | Provide professional financial users with real-time market data, analytics, news, messaging, and workflow tools in one terminal. |
| Target Users | Institutional traders, portfolio managers, analysts, sales/trading desks, risk teams, and financial professionals. |
| Primary Value Proposition | High-trust market intelligence and execution workflow density in a single professional environment. |
| Primary Workflows | Market monitoring, security lookup, charting, news, analytics, messaging, portfolio/risk review, trade support. |
| Core Philosophy | Professional speed through dense, command-driven, multi-window access to trusted data. |

## 3. Information Architecture

Navigation is command-first, workspace-oriented, and optimized for expert recall. Hierarchy is function-based rather than marketing-based. Grouping is deep and asset-class aware. Progressive disclosure exists through functions, tickers, panels, and drilldowns, but assumes trained users. Density is extremely high. Search is integrated through ticker/function discovery. Filtering is powerful but expert-oriented. Workspace value comes from persistent multi-panel layouts.

## 4. Visualization

Charts are utilitarian and data-rich. Cards are less central than terminal functions. Heatmaps, tables, monitors, and analytics views dominate professional workflows. Timelines exist through news and event functions. Network graphs are not the core metaphor. Animations are minimal. Typography and spacing favor density. Color language is functional and iconic rather than modern.

## 5. Decision Support

Users reach conclusions by combining price, news, analytics, comps, messages, and desk context. Evidence is available but often assumes domain expertise. Reasoning remains user-driven. Historical context and comparison are strong. Confidence comes from data trust rather than UI explanation. Warnings and counter-evidence depend on user workflow construction.

## 6. UX

Learning curve is high. Onboarding is training-heavy. Interaction is command, keyboard, multi-window, and expert-search driven. Customization is strong. Productivity is exceptional for trained users. Desktop is the primary mode. Mobile is secondary. Accessibility is not the dominant product posture.

## 7. Strengths

- Extreme professional density.
- Command-driven speed.
- Trusted source position.
- Integrated workflows across data, news, analytics, and communication.
- Multi-window productivity.

## 8. Weaknesses

- High learning curve.
- Difficult beginner orientation.
- Visual language can feel dated.
- Trust is embedded in brand and data access more than explainable UX.
- Expensive, institution-first posture.
