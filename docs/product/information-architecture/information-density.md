# Information Density

**Status:** Canonical density model  
**Owner:** Product / Design  

## Purpose

Information density defines how QuantTerminal expands from simple orientation
to professional depth without overwhelming users.

## Density Ladder

| Level | User mode | Information depth | Typical screens |
| ---: | --- | --- | --- |
| Level 1 | Beginner | Headline, primary state, one clear evidence group. | Dashboard, mobile companion. |
| Level 2 | Intermediate | Evidence Cards, charts, key warnings, filtered candidates. | Dashboard, Markets, Scanner, Trade. |
| Level 3 | Professional | Dense panels, comparisons, derivatives clusters, saved context. | Markets, Trade, Replay, Research. |
| Level 4 | Research | Thesis, support, counter-evidence, charts, sources, historical context. | Research, Replay. |
| Level 5 | Repository | Raw records, metadata, source, freshness, audit trail. | Repository, expert drilldown. |

## Expansion Rules

- Beginner mode starts with orientation.
- Intermediate mode adds evidence and filtering.
- Professional mode adds density and workspace.
- Research mode adds depth and counter-evidence.
- Repository mode adds audit detail.

## Density Anti-Rules

- Do not show all levels at once.
- Do not make raw records first-read content.
- Do not bury warnings below dense tables.
- Do not use density to imply certainty.
- Do not repeat the same metric without a distinct purpose.

## Screen Density Guidance

| Screen | Default density |
| --- | --- |
| Dashboard | Level 1 to Level 2. |
| Markets | Level 2 to Level 3. |
| Scanner | Level 2. |
| Trade | Level 2 to Level 3. |
| Replay | Level 2 to Level 4. |
| Research | Level 3 to Level 5. |
| Repository | Level 5. |

## Validation

Information density aligns with:

- 5-Second Rule;
- Progressive Disclosure;
- Professional Density With Progressive Disclosure;
- Accessibility State Redundancy;
- responsiveness.
