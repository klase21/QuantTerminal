# Ticker Animation / Flash Update

Applied:
- Top ticker marquee speed reduced from 28 to 12.
- Macro ticker animation duration extended to 180s.
- Top ticker price and 24h change flash when values update.
- Macro ticker value and change flash when values update.
- Flash effect:
  - green background for uptick
  - red background for downtick

Goal:
- reduce visible marquee reset/jump
- preserve subtle ticker movement
- make value changes visible without noisy animation
