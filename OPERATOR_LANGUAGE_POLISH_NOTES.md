# Operator Language Polish

This pass removes internal enum-style labels from the visible product surface while keeping TypeScript identifiers and engine enums unchanged.

## UI Copy Changes

- `FLOW_ONLY` is rendered as `Liquidity Expansion`
- `ROTATION_ONLY` is rendered as `Rotation Detected`
- `VALIDATED` is rendered as `Narrative Confirmed`
- `NEWS_ONLY` is rendered as `News Momentum`
- `HIGH_TRUST` is rendered as `High Conviction`
- `LOW_QUALITY` is rendered as `Weak Signal`
- `WATCH` is rendered as `Monitor`
- `P1 / P2 / P3` are rendered as `High / Medium / Low Conviction`
- `Quality Score` is rendered as `Confidence`
- `DIV` is rendered as `DIVERGENCE`

## Productization Changes

Signal inbox titles now use market/operator language, for example:

- `AI Narrative Confirmed`
- `L1 Liquidity Expansion`
- `INFRA Rotation Detected`

Generic watchlist copy was replaced with contextual operator commentary where possible.
