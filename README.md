# QuantTerminal

Real-time crypto market intelligence terminal focused on:

* Aggregated crypto news
* On-chain & perpetual exchange activity
* Prediction market sentiment
* Trading signals & dashboards
* Multi-source translated global news

---

## Features

### News Aggregation

* Aggregates crypto news from multiple sources
* Chinese crypto media translation pipeline
* Real-time market headlines
* Fast searchable feed

### Market Data

* Perpetual exchange monitoring
* On-chain activity tracking
* Funding rates & open interest
* Liquidation monitoring

### Prediction Markets

* Polymarket integration
* Kalshi market sentiment
* Event probability tracking

### UI / UX

* Live dashboards
* Responsive terminal-style interface
* Fast updates & lightweight rendering
