
# QuantTerminal

Geopolitical + Market Intelligence Terminal for Crypto Traders and Exchange Strategy Teams.

## Included
- Multi-panel terminal layout
- Sentiment heatmap architecture
- Macro intelligence widgets
- AI narrative engine scaffold
- Orderflow stream mock
- Trading dashboard UI
- Realtime websocket structure

## Stack
- Next.js
- TypeScript
- TailwindCSS
- Zustand
- Lightweight Charts
- Framer Motion

## Start
```bash
npm install
npm run dev
```
